Tower defense game using character inspired by pokemon and gameplay inspired by PvZ but with fast-paced gameplay, evolution mechanics, energy bar, and health bar

How to play 
- Right click on or nearby circle to spawn a monster (consume 1 energy)
- Left click to evolve (consume 2 energy)
- Use 1 and 2 key to change type of monster to spawn 
- Defend your base from enemy
- Enemy's spawn rate increase as the game goes on
- If 3 enemies reach your base its GAME OVER
